## Short Version

Subject: Support OrgAnchor Fireseed Alpha

Hello,

OrgAnchor is an open-source project for lowering the cost of discovering, screening, verifying, understanding, and comparing candidate organizations. It helps organizations publish signed, recheckable public records that link identity, official presence, claims, evidence, and migration history so people and AI agents can verify who is speaking, where that organization's official presence can be found, what evidence exists, what is stale or missing, and what should be checked next.

The project is now in Fireseed Alpha. It has a working CLI, public `/verify` model, AI-agent verification output, signed official-presence records, claims/evidence manifests, Beacon discovery, and local demo flows. It is not stable v1, not a trust badge, not a marketplace, and not a certification authority.

We are looking for supporters who want to help fund a defined external validation wave:

- Public explainer and demo materials.
- First low-risk external pilot.
- Technical review.
- Evidence and governance review.
- AI-agent and Directory discovery experiments.
- Documentation and example packages for adopters.

Sponsorship does not buy listing priority, Directory priority, trust status, verification results, or policy influence. It supports open development and public validation.

Project links:

- `https://organchor.org/verify/`
- `https://github.com/OrgAnchor/OrgAnchor`

Thank you for considering support.

## Detailed Version

Subject: Sponsoring a Fireseed Alpha project for lower-cost organization verification

Hello,

I am reaching out about OrgAnchor, an open-source project designed to reduce the cost of discovering, verifying, understanding, and comparing organizations before deeper review, contact, partnership, purchase, or support.

The core problem is simple: organizations increasingly live through domains, websites, platforms, cloud providers, archives, and mirrors. These carriers are useful, but fragile. At the same time, AI-generated media and polished pages make appearance cheaper than evidence. For people and AI agents, the important question becomes:

- Who is speaking?
- Is this the same organization over time?
- Where can its official presence be found now?
- Which claims are signed?
- Which evidence supports them?
- What is stale, missing, contradicted, or outside scope?
- What should be checked next before a transaction, partnership, listing, or safety decision?

OrgAnchor's answer is to make the verification path explicit:

- Organization root authority.
- Signed official-presence records.
- Public `/verify` package.
- Machine-readable `/.well-known/organchor.json`.
- AI-agent compact verification output.
- Signed claims and evidence manifests.
- Carrier receipts for web, IPFS, Arweave, OpenTimestamps/Bitcoin, Onion, ENS, and Directory experiments.

The current Fireseed Alpha is a serious seed, not a finished trust infrastructure. It demonstrates the minimum useful loop and exposes current limits. In particular, S1-S3 evidence has an alpha baseline, while S4/S5 real-use observation and public challenge remain design-preview areas that need external critique and co-building.

We are seeking support for a defined Fireseed Alpha validation wave:

- Producing public explanation and demo materials.
- Supporting the first low-risk external pilot.
- Funding independent technical review.
- Funding evidence/governance review.
- Improving AI-agent and Directory discovery compatibility.
- Maintaining package integrity, examples, and adopter documentation.

Important boundary:

Sponsorship must not buy ranking, certification, verification outcomes, Directory priority, trust status, or influence over whether another organization passes or fails a check. OrgAnchor should remain a protocol and tooling project that makes identity and evidence materials more inspectable, not a paid trust gate.

Thank you.
