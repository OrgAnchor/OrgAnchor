# Self-Pilot Templates

These templates are for the future official OrgAnchor public self-pilot workspace.

They are not official signed artifacts.

## Files

- `organchor.config.template.json`: configuration template to copy into the self-pilot workspace after the final domain is chosen.

## Replacement Values

Before use, replace:

```text
<domain>
<to-be-confirmed>
```

Do not create official root private keys until the root key ceremony is explicitly confirmed.
