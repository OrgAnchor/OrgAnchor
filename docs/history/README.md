# Historical Records

Documents in this directory preserve decisions, audits, prechecks, and project
state snapshots from specific dates. They are evidence of what was known or
decided at that time, not current operating instructions.

## Rules

- Do not use a historical snapshot as the current implementation source of truth.
- Do not rewrite historical results merely because the project later changed.
- Use `docs/project/IMPLEMENTATION_STATUS.md` for current capability state.
- Use `docs/operations/` for current release and operating gates.
- Use the latest applicable public self-verification snapshot only when reviewing
  a specific published release.
