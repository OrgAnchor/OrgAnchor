# Agent Evidence Interpretation Results

This directory preserves bounded Agent evaluation evidence. Each retained run separates the uncorrected Agent answer, deterministic score, operator configuration, runtime metadata, and reviewer notes.

## Summaries

- `WAVE1_SUMMARY.md`: three isolated fresh-context configurations evaluated signed-but-weak product-lifetime evidence.
- `WAVE2_CALIBRATION_SUMMARY.md`: two isolated fixed-time stale-evidence runs, the internal `--compact` versus `--brief` machine-friction comparison, and remaining provider-diversity limits.

## Classification Rule

`INDEPENDENT` means the run was performed in a fresh context that did not participate in implementation and satisfied the recorded isolation contract.

`INTERNAL_CALIBRATION` means the run is useful engineering evidence but was operated by the implementation process. It must not be presented as independent external validation.

No score in this directory is an organization, supplier, product, certificate, or procurement rating. The scenarios are fictional and each scorer is limited to its declared question.
